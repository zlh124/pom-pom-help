# 板块说明（收录边界）

| 板块 | 收什么 | 不收什么 | 主要来源 |
| --- | --- | --- | --- |
| characters | 角色设定/故事/语音、配装 | 强度排行（放 guides） | BWIKI 图鉴、社区实测 |
| world | 星神命途、星球地区、阵营、编年史、名词 | 剧情全文 | BWIKI、官方公告 |
| ingame | 书籍、短信、任务、成就、道具/光锥/遗器文案、奇物祝福、局内事件 | 大段剧情原文 | BWIKI 模板 |
| enemies | 敌人属性/弱点/技能/机制 | 伤害计算表 | BWIKI 敌人页 |
| npcs | 列车组、各星球 NPC、组织/商人 | 完整对话树 | BWIKI NPC 页 |
| systems | 玩法机制/公式/规则 | 具体角色推荐 | BWIKI 攻略/官方说明 |
| guides | 可执行结论：配队、材料、新手、终局、FAQ | 纯数据罗列 | 社区 + 实测 |
| live | 版本内容、活动、卡池 | 前瞻猜测 | 官方公告 |
| quiz | 帕姆问问每周题组 | — | 自建 |
| persona | 帕姆人设/语气/规则 | — | 自建 |
| meta | schema/板块说明/来源登记/术语表 | — | 自建 |

新增板块或子目录：改 `corpus/taxonomy.yaml` 的 `blocks`，然后跑 `npm run corpus:check`。
