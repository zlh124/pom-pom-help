# 击破与持续伤害机制

> 给「为什么我的击破队打不出伤害」「持续伤害怎么算」这类问题一个能自行查证的答案。

## 1. 削韧与弱点击破

- 敌人血条上方有一段「韧性条」。**只有用敌人弱点对应的属性攻击，才会削减韧性**。
- 韧性削到 0 → 触发**弱点击破**：敌人行动延后、打断引导，并受到击破伤害 + 属性异常。
- 不同攻击方式削韧值不同：普攻、战技、终结技、追加攻击、弹射各有差异；**终结技不一定比普攻削韧更高**。
- **击破特攻 ≠ 弱点击破效率**：击破特攻提高击破伤害与部分异常强度；弱点击破效率提高削韧值（削韧量）。这是新手最常见的混淆点。

## 2. 七种属性的击破效果（简述）

| 属性 | 击破附加 | 特点 |
| --- | --- | --- |
| 物理 | 裂伤（持续伤害） | 对精英/首领有百分比生命伤害 |
| 火 | 灼烧 | 破盾伤害高，持续伤害弱 |
| 冰 | 冻结 | 控制强，伤害弱 |
| 雷 | 触电 | 破盾伤害低，持续伤害高 |
| 风 | 风化（可叠层） | 对精英效果好，初始持续 2 回合 |
| 量子 | 纠缠 | 伤害下限低、上限高，攻击会提高附加伤害 |
| 虚数 | 禁锢 | 强控：额外延后行动并减速 |

## 3. 伤害怎么算（概念版）

- **击破触发伤害** ≈ 基础伤害（由角色等级决定）× 属性系数 × 韧性系数 × (1 + 击破特攻)。
- **击破持续伤害** ≈ 基础伤害 × 属性持续伤害系数 × (1 + 击破特攻)。
- 物理持续伤害是特例：按百分比生命计算。
- 所以击破队**优先拉等级、堆击破特攻**；攻击力、双暴对击破伤害没有帮助。

## 4. 持续伤害（DoT）

- DoT 按回合结算，吃施加者的攻击力、增伤、击破特攻（击破系 DoT）等。
- DoT 队的关键是「层数 × 引爆频率」：卡芙卡能立即引爆队友的 DoT，所以速度比单纯堆攻击更值。
- 卡芙卡 4.0 加强后，效果命中 ≥75% 的队友能吃到大量攻击力加成，DoT 队配装要凑档。

## 5. 超击破

超击破是击破体系的分支：在**敌人处于弱点击破状态**的窗口内，把击破转化为额外伤害。
它只吃角色等级、击破特攻、削韧值、超击破/击破伤害提升，以及敌方防御/抗性/易伤，
**不吃攻击力、双暴、常规增伤**——所以流萤队和直伤队的养法完全不同。
