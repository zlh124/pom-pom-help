## 1. 产品定位与基本信息

### 1.1 一句话定位

游戏内 **AI 列车长助手**：以吉祥物「帕姆」为人格载体，用自然语言对话完成「闲聊陪伴 + 攻略问答」，并把攻略结果做成**可直接操作的游戏内卡片**（查看/解释/应用方案）。这是米哈游首次在成熟产品中落地大模型 AI，定位是「不只是工具，而是有记忆的 AI NPC」。来源：<https://www.163.com/dy/article/KRACCUJH052682V2.html>（游戏日报）、<https://news.qq.com/rain/a/20260424A08PB300>（游戏陀螺）

**关键设计洞察：**
- AI 回复不是纯文本，而是「人设开场白 + 结构化卡片」两段式。
- 卡片同时给出**当前状态**与**推荐方案**，形成对比；并对当前配置给出负面诊断（主属性不匹配）。
- 「应用方案」= 把 AI 建议变成**一键可执行操作**，是这套系统区别于外部攻略站的核心。
- 推荐附带「评级（S）」「有效副词条数」这类可量化解释，降低“AI 胡说”的不信任感。

### 2.2 对话与卡片的交互链路 [已证实 + 社区观察]

1. 玩家口语化提问（例：「帮我推荐一下火花的遗器」）。
2. 帕姆识别意图（角色名支持非规范简称/错别字，如「火花」→花火），回复人设开场白。
3. 系统读取**玩家账号内已有遗器/光锥/角色**，生成候选方案。
4. 卡片展示：当前装备（含评级、主属性诊断）↔ 推荐方案（评级、套装来源、有效副词条）。
5. 玩家可点「查看」（看详情）/「解释」（让 AI 讲推荐逻辑）/「应用方案」（一键替换装备）。
6. 可继续追问，AI 自动补全主语（例：先问「流萤用什么光锥」，再问「那遗器呢」）。

来源：<https://www.163.com/dy/article/KRA6VUPK0517RQV8.html>（玩家实测：25 词条遗器被帕姆筛出 27 词条方案并一键应用）

## 3. 功能清单（完整）

### 3.1 对话与陪伴
- 日常闲聊：列车日常、旅途趣闻、角色八卦（会被“星际和平公司”以世界观内方式拦截）。
- 保持帕姆人设：`帕`字口癖、列车长口吻、颜文字/表情符号，**不 OOC** [已证实]。
- 长线记忆：记住玩家偏好与话题方向；多轮上下文自动补全主语 [已证实]。
- 未实装/机密内容「萌混过关」而非硬性拒答 [媒体观察]。
- 玩家“调戏”彩蛋：例如索要星琼、谎称三月七被绑架，被帕姆拆穿（「三月七还好好的呢」「你说的朋友就是你吧」）[媒体观察]

### 3.2 攻略问答（四大类）
材料刷取 / 配队推荐 / 遗器推荐 / 光锥推荐。特点：
- 基于**玩家账号数据**给个性化方案（不只是通用攻略）。
- 方案可解释（评级、有效副词条、来源套装）。
- 方案可执行（一键应用）。
- 配队按玩法节点、甚至 buff 选择给建议。

### 3.3 帕姆问问（第二周起的周常）
见第 4 节。

### 3.4 衣装与奖励系统
- 「更换」：在帕姆帮帮界面内快速更换衣装（联动游戏既有「千面帕姆」衣装系统）。
- 奖励进度：累计对话 10 次 → 衣装；每周问答 → 50 星琼。
- 4.3 后：黑塔商店用黑塔债券兑换该衣装（说明它从“限时活动奖励”降级为“常规兑换物”）。

### 3.5 合规与设置
- 常驻 AI 免责声明（对话头 + 答题页底部）。
- 「…」菜单 →【数据设置】：可关闭“对话内容用于模型训练”。
- 「问题反馈」入口：收集体验期反馈。
- 输入内容需遵守发言规范（官方注意事项）。

## 4. 「帕姆问问」玩法详解

### 4.1 规则 [已证实/多方一致]
- **形式**：每周一次的知识问答，**共 10 题**。
- **奖励**：**无论对错**，完成即得 **50 星琼**（周常）。
- **主题**：每周不同主题；题目覆盖主线、支线、地图彩蛋、角色语音、角色故事。
- **反馈**：每题后有帕姆的简短讲解；全部完成后帕姆按成绩点评。
- **难度**：连续答对常规题后**自动提升难度**，转向冷门考据题。
- **标签**：按答题表现生成趣味标签（见 4.3）。
- **入口行为**：答题界面左下角有「暂时离开」，可切回帕姆帮帮查答案再回来（玩家戏称“以子之矛攻子之盾”）。

来源：<https://news.sohu.com/a/1015893091_120444808>、<https://www.163.com/dy/article/KRM84HOD0517RQV8.html>、<https://news.17173.com/content/04212026/105557458.shtml>

### 4.2 题目示例（真实玩家截图/报道转述）
- 「星期日小时候因为在音乐课前吃了几个蛋挞被老师罚站？」（判断题式）
- 「砂金的瞳色由哪三种颜色组成」
- 「橡木家系有多少名成员成为梦主歌斐木的意识载体？」
- 「海瑟音的左眼下有几枚白色鱼鳞」
- 「孤云的剑匣外壳上嵌入金属丝勾勒的是什么纹样」
- 「红A的衣服下摆有几条」
- 「拉姆和同为天才俱乐部的谁离婚了又复婚了」
- 姬子相关：以“姬子的咖啡/黑色液体”为题面（见 `refs/weekly.png` 的「味觉故障的天才」）

### 4.3 结果页标签（真实出现过的标签）
- 全错方向：「十题全缘」「疑似橡木人」
- 7 题：「七分熟的开拓者」「丹恒同款记忆力」
- 其他：「满分通关成就」「博士尊的凝视」「六十分万岁」

### 4.4 失败/极端反馈 [社区观察]
- 玩家故意全错时，帕姆**沉默了约 30 秒**，随后分析全错原因，表示“下次出题前提前给开拓者补课”。
- 玩家普遍反馈“比通关王棋还难”“汗流浃背”，题目偏冷门考据。
- 存在“逃课”最优解：不会的题点「暂时离开」去问帕姆帮帮。

同页其余原文要点：
> 「「帕姆帮帮（测试版）」功能中，帕姆的全部对话内容均由人工智能技术生成，回复内容可能与客观情况存在出入，仅供娱乐参考，不代表官方观点或立场。」
> 「…在经安全加密技术处理、严格去标识化且无法重新识别特定个人的前提下，我们可能会将…内容数据进行分析和用于模型训练…如果开拓者不希望…可以通过点击「帕姆帮帮（测试版）」界面右上角【…】-【数据设置】来关闭此设置。」

来源：<https://wiki.biligame.com/sr/?curid=38178>；公告原始页 <https://www.miyoushe.com/sr/article/74728255>

### 6.2 下线原因分析
- **官方口径**：暂时下线优化，非永久关停；正式版时间未公布。[已证实]
- **可推断因素**（[未证实]，仅分析）：
  1. 测试版定位，需要收集反馈迭代（官方明确说“欢迎提交反馈，为帕姆的学习提供支持”）。
  2. 千万级并发的算力成本压力（“受限于当下的算力成本，初版在智商上做了妥协”）。
  3. 攻略建议的准确性与责任风险（免责声明反复强调“可能与客观情况存在出入”）。
  4. 跨区服能力不一致（繁中/国际服未同步）。
- **下线后玩家反应**：社区出现“找不到入口”的询问；功能整体评价偏正面，属于“好用的限时测试”而非“被骂下线”。

### 8.3 对话流程（状态机）

```
[空会话]
  → 展示欢迎语 + 4 个引导词条（配队/遗器/光锥/材料）
  → 用户输入
  → 意图识别（角色 + 诉求）
      ├─ 实体缺失（没说角色） → 追问“你想问哪位乘客帕？”
      ├─ 闲聊意图 → 纯文本气泡（人设化）
      └─ 攻略意图 → 文本开场白 + ToolCard
  → 卡片动作
      ├─ 查看 → 展开详情（遗器主/副词条、套装来源）
      ├─ 解释 → 帕姆用自然语言解释“为什么推荐这套”
      ├─ 应用 → 网页版替代：一键复制配置文本 / 复制到剪贴板 / 打开 wiki 链接
      └─ 追问 → 保持上下文，自动补全主语
  → 会话结束（开启新对话 / 刷新）
```

状态与异常：
- **加载**：先出“帕姆正在思考…”，再流式出文本，最后挂卡片（避免空窗）。
- **模型不可用/超时**：降级为「预设攻略卡 + 帕姆口吻文案」，并提示“可去 wiki 查看”。
- **数据缺失**（网页版无账号数据）：用户手动选择角色/练度，或提供“通用推荐”模式。
- **敏感/剧透**：按世界观内方式回应 + 提供“剧透折叠”。

### 8.4 游戏数据卡片的呈现（复刻重点）

**遗器卡（双栏对比）**
```
┌ 当前装备遗器 ───────────────────── 暂无评级 ┐
│ [遗器A +15] [B +15] [C +0⚠] [D +15]   🔍 查看 │
│ ⚠ 遗器主属性不匹配                            │
├ 根据高使用率套装和拥有遗器推荐 ────── 评级 S ┤
│ [套装1×4] [套装2×2]   [解释] [应用方案]      │
│ 总有效副属性 22，已达最高评级                 │
└──────────────────────────────────────────────┘
```
- **评级徽章**（S/A/B）与**数值理由**（有效副词条数）必须同时出现。
- **负面诊断用红色警示条**（主属性不匹配），比纯推荐更有“顾问感”。
- 「应用方案」网页化：`一键复制配置`（角色/套装/主副词条/光锥）或`跳转 wiki 配装页`；用 toast 反馈“已复制”。

**光锥卡**：列表 + 「只显示可获得」开关 + 获取途径标签（跃迁/商店/活动）。
**配队卡**：方案 Tab（已有角色优先 / 高使用率），每个位置显示角色头像 + 光锥 + 遗器简写；可按玩法（虚构叙事/忘却之庭）切换并显示节点 buff。
**材料卡**：材料图标 + 数量 + 副本来源 + “去刷”跳转外部地图/wiki。

### 8.5 「帕姆问问」网页版规格

- 开始页：本周主题名 + 「10 题 · 完成得 50 星琼（网页版：徽章/积分）」+ 开始。
- 答题页：进度条 `n/10`；题干在「帕姆对话卡」内；三选一。网络版保留「暂时离开」→ 跳回聊天页查答案（复刻原作“逃课”彩蛋，并做成彩蛋成就）。
- 反馈：每题即时对错 + 帕姆一句讲解（1–2 行），错误不惩罚。
- 结果页：分数、帕姆点评（按分数段写死模板 + 变量）、2–3 个趣味标签；按钮「再试一次」「确认并退出」。
- 奖励：网页版用「收集徽章 / 帕姆好感度」替代星琼，避免与真实游戏经济混淆。

### 8.6 视觉与内容注意

- **保留**：左栏帕姆立绘 + 聊天气泡的“纸感”配色；顶部免责声明；口癖「帕」；表情符号；卡片圆角 + 浅纸底。
- **替换**：所有官方美术资产 → 自制/同人风格；星琼、遗器图标 → 通用图标；装备“应用” → 复制/跳转。
- **必须声明**：页脚「非官方粉丝复刻，与米哈游无关；AI 生成内容仅供参考」。
- **可用性**：手机端左栏折叠为顶部头像条；卡片横向滚动；输入框固定底部。
- **可玩性差异点**：网页版可加入“帕姆好感度/记忆档案”本地存档，弥补原作下线后的缺失感。
